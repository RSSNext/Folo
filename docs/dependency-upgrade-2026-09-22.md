# Dependency upgrade audit — 2026-09-22

Status: source review, installation and the documented local functional acceptance checks are complete. External-service and platform limits are recorded below. This audit records the completed local validation before the separately authorized dev publication.

## Method and scope

The starting inventory contained 207 outdated direct packages, plus the explicit Floating UI DOM override. Comparing effective manifest versions (including catalog and override resolution) with HEAD gives 205 upgraded existing direct packages, one new direct package (`@lexical/code-prism`), and two changed override-only packages (`@floating-ui/dom`, `react-server-dom-webpack`). The original TypeScript and legacy Vite plugin versions remain unchanged for documented compatibility reasons. pnpm is an additional toolchain upgrade. All 208 package candidates have a recorded version decision. The package manager was subsequently added to the toolchain review (pnpm 10.17.0 → 12.5.1). Each updated dependency was reviewed against upstream changelog/release material and actual package source diffs; relevant shared runtime was included. Large monorepos were narrowed to consumed packages. Generated bundles, unrelated integrations and unrelated framework implementations were excluded; this is not a claim that every upstream line was read.

Exact npm metadata, refs, raw diffs and focused source diffs are retained in `/tmp/folo-dependency-review-20260922`, `/tmp/follow-runtime-audit` and `/tmp/follow-tooling-audit`. These are temporary session evidence; the source URLs and family reports below are the durable record. Official commit histories substitute only when projects have no conventional changelog (including DefinitelyTyped, generated icon data and ai-tools). Such substitutions are identified in the corresponding notes.

## Compatibility decisions

- React/React DOM use 19.2.8, the latest compatible patch for Expo 57 / React Native 0.86.3's React 19.2 renderer, with a single workspace React version.
- Expo uses the latest SDK 57 patches and its supported React Native 0.86.3. Babel stays on 7.29.7 because Expo preset 57 and NativeWind require Babel 7.
- Mobile NativeWind uses Tailwind 3.4.19; desktop/landing use Tailwind 4.3.3. Mobile resolves its own Tailwind types.
- Electron Vite 5 uses Vite 7.3.6, React plugin 5.2.0 and legacy plugin 7.2.1. The newest legacy plugin 8 requires Vite 8/Rolldown's chunk APIs. Worker/landing use separately reviewed Vite 8 / React plugin 6.
- TypeScript stays on 6.0.3: the real TypeScript 7.0.2 substitution fails in typescript-eslint because its package exports no JS compiler API. See the [executable compatibility investigation](dependency-upgrade-typescript-2026-09-22.md).
- `@vercel/node` uses 12.0.1, the latest release with public source/changelog provenance. Version 13.0.1 has identical published runtime but an untraceable newer build-utils peer. See [source verification](dependency-upgrade-vercel-node-2026-09-22.md).

- pnpm 12.5.1 migrates `.npmrc` layout policy into workspace settings, replaces `onlyBuiltDependencies` with `allowBuilds`, removes the obsolete `ignorePatchFailures: false` flag, and preserves one consistent hoisted dependency layout throughout mobile CI (see the post-publication configuration fix in the package-manager audit). Frozen installation and graph checks are recorded in [the package-manager audit](dependency-upgrade-pnpm-2026-09-22.md).

## Required adaptations

- Better Auth account selectors now use local account IDs. Expo's asynchronous cookies and atomic chunk storage protocol are implemented and tested.
- Jotai 3 removed private storage type paths; types derive from public `createJSONStorage`.
- The jsdom 30 desktop package graph no longer contains `symbol-tree`; removing the stale Forge copy entry fixes a real package-generation failure. Unsigned `.app` creation and packaged runtime module loading passed. - Electron 44 removes renderer `clipboard`: importing it caused a real preload failure and disabled all IPC. The preload now retains standard `navigator.clipboard`; main-process read IPC returns a promise. Removed `openAsHidden` is replaced by the existing startup argument.
- Motion modal enter frames and event subscriptions now clean up on unmount. Real browser E2E exposed a delayed `controls.start()` after the modal unmounted.
- Lexical 0.51 requires explicit `@lexical/code-prism`; the real editor imports the replacement highlighter.
- unplugin-ast uses typed Yuku nodes. Its Tailwind template transformation was checked for whitespace, interpolation and unrelated tags.
- OTA tar chunks use Uint8Array validation and the current stream completion signature.
- Firebase uses modular native APIs and App Check retry handling; Expo IAP uses `verifyPurchase`. Exact PostHog/React peers avoid duplicate runtime instances.
- Worker Satori/HarfBuzz and resvg assets, landing request boundaries and Worker context changes are documented in their family reports.
- UIKit 1.0 changes its consumed Tailwind sibling to `color-mix`, which dropped nine native alpha colors. A dynamic RGB/alpha-variable adapter preserves the official palette and opacity multiplication; see the [counterfactual compilation and native resolver tests](dependency-upgrade-mobile-2026-09-22.md#uikit-alpha-regression-and-continuous-test-coverage). ## Test side effect

The first native clipboard probe used Electron read handles directly when restoring. Electron 44 rejected those handles, leaving the test PNG in the system clipboard. That process exited without a materialized copy of the original contents, so the pre-test clipboard could not be recovered. Subsequent runs materialize every MIME payload before writing and correctly restore their own starting state; that does not recover the original clipboard. No clipboard contents were logged.
