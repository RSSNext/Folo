## UIKit alpha regression and continuous test coverage

The initial review was too narrow: `react-native-uikit-colors/tailwind` re-exports its sibling `tailwindcss-uikit-colors`, so that sibling is consumed runtime. A follow-up read covered the full `generate-tailwind-config.ts` and `src/tailwind.ts` changes between the exact refs linked above, and checked the published 0.6.2/1.0.0 tarballs. The generator deliberately replaced `rgba(var(...))` with `color-mix(...)` to support opacity modifiers. Core Apple palette values and native hooks are unchanged. This is an upgrade regression, rather than an existing color defect.

Counterfactual compilation against the same installed Tailwind 3 / CSSInterop 0.2.7 toolchain produced 9/9 declarations with published UIKit 0.6.2, 0/9 with unadapted 1.0.0, and 9/9 after adaptation. `withNativeUIKit` replaces only the nine dynamic alpha-color entries; `RootProviders` supplies numeric RGB and intrinsic-alpha variables from `useColorsVariants`, retaining the official light/dark palette. Native `rgb` and `calc` support opacity multiplication without `color-mix` or hardcoded substitute colors.

The regression tests compile all nine semantic classes with and without `/50`. They also run the actual published CSSInterop native `resolveValue` implementation with mocked platform services: separator resolves to alpha 0.34/0.6, system fill `/50` to 0.1/0.18, and secondary label to the official light/dark RGB with alpha 0.6. Evidence: `/tmp/folo-uikit-alpha-audit/{consumed-source.diff,compile-comparison.log}` and `apps/mobile/scripts/uikit-colors.test.ts`. Final simulator screenshots and theme interactions are recorded in the native platform reports.

The mobile and HTML-renderer packages now expose their existing Vitest configurations through `scripts.test`, so root recursive tests include their auth, purchase, migration and reader regressions. Existing TTS/spotlight tests use the Vitest runner, release-script tests resolve fixtures from their own file URL, and GitHub-output assertions check the existing delimiter format. These changes fix test discovery/cwd assumptions without changing release scripts.
