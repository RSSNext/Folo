## Validation status

Source review and local Node/Worker/browser verification completed on the installed final dependencies.

### Runtime adaptations confirmed by E2E

- Satori 0.33 adds HarfBuzz. Its Emscripten loader assumes browser-worker location or Node filesystem loading, neither of which matches workerd's precompiled WASM modules. The build plugin resolves the loader, API and WASM through Satori, supplies an imported compiled module, and guards both exact loader assumptions so an upstream change fails the build for review.
- The deployment workflow now copies resvg WASM from the SSR workspace dependency. The old root path resolved a different resvg version and produced a real `LinkError` in workerd despite a successful build.
- Font generation preserves language subsets instead of overwriting each weight with the last subset. Satori receives a distinct family per subset so Latin, accented Latin, Cyrillic and Chinese fallbacks render rather than tofu.
- Actual remote feed icons could hang or disconnect. Image loading now has a five-second deadline and rejects non-image/error responses, falling back to initials. A missing profile's SDK 404 becomes an OG 404 while other failures retain their original error handling.
