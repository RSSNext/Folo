## Changes and application impact

- Runner scheduling adds named locks and optional isolated retries; the default remains immediate retries. Folo uses one worker and no new options. Teardown projects now run after `maxFailures`; graceful worker shutdown sends heartbeats, so a live slow teardown is not killed merely for taking longer than the parent timeout. Reporter errors now fail an otherwise passing run. Trace schema moves to version 9, with different source/attachment paths and explicit subtitles/parameters; Folo uses the bundled HTML/list reporters and does not parse trace internals.
- New component stories, WebP screenshots, AbortSignal cancellation, cross-frame locators, visibility filtering, OPFS/passkey storage persistence, and expanded media options are opt-in. Existing action timeouts and automatic scrolling remain the defaults. Removed experimental component-test internals and private Babel-plugin configuration are unused here. The 1.62.1 TS-config regressions were corrected; net source diff retains the previous permissive resolution behavior.
- Frame lookup is consolidated into one selector callback path. Strict locators still reject multiple elements, absent nodes retain hidden/detached and zero-count assertion semantics, and actions still retry detached nodes. Cross-frame search refuses matches in more than one frame; ordinary selectors continue to resolve in one frame. Aria references receive a new frame sequence after a full navigation, preventing references from accidentally matching a new document.
- Chromium response-body fallback now refetches only safe GET subresources/prefetches, preventing duplicate POST or other side effects during tracing. Intercepted requests remove the captured `cookie` override and let Chromium use its cookie store. This directly affects authentication checks that intercept network requests. EventSource requests no longer prevent network idle; waits should still use page state or URL where practical.
- Electron's page close uses main-process `webContents.close`, avoiding a CDP close/navigation race; the default still skips beforeunload unless requested. Launch retains explicit environment and timeout support. `firstWindow` still returns an available initial window, so the repository helper must wait for a non-`about:` URL and DOMContentLoaded before injecting renderer helpers. Crash/close now consistently dispose pending requests and contexts.
- Browser payloads change from Chromium 149 to 153.0.8010.12, Firefox 151 to 155, and WebKit 26.5 to 26.6. Install the matching Chromium browser before the web E2E run. Debian 11 and Ubuntu 20.04 are no longer supported; repository CI and this macOS host do not target them. Linux arm64 now uses Chrome for Testing.

Frontend agent owns installation and the existing web/Electron end-to-end runs. Require real authentication, navigation, settings persistence, report generation, and clean Electron shutdown after the update. Existing runs on 1.61.1 are baseline evidence only, not validation of 1.63.0.
