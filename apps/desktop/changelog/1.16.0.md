# What's new in v1.16.0

## Shiny new things

- Two-factor authentication setup now has a "Copy setup key" button for authenticator apps that can't scan the QR code

## Improvements

- Smoother timeline, sidebar, reader and AI chat: fewer re-renders while answers stream, entries update or the selection changes, and the search index is built only when search opens
- Much better keyboard and screen reader support: icon-only buttons, switches and window controls are named, and menus, pickers, the update notice and shortcut recording work from the keyboard
- Clearer errors: the server's validation errors show under the field they concern, invalid handles, list titles, category names and regex patterns are explained, and a timeline, sidebar or entry that fails to load offers a retry
- Follow, inbox and action forms ask before closing with unsaved changes, and deleting a custom AI shortcut or integration asks first
- The window reopens on the display it was on, maximized if it was
- Typing a website address into Discover lists the site's feeds, and a new feed address opens its preview
- The entry list follows your Date Format setting
- Features that need a paid plan, such as hiding a list from the timeline, following a list privately, BYOK and AI tasks, are now labeled and offer an upgrade
- Exported files are named after Folo, such as folo.opml

## No longer broken

- Fixed timelines opened from Discover, the AI page and other pages showing the wrong view with an empty header and never marking entries read on scroll
- Fixed the last entries of a timeline staying unread after scrolling to the end, and hover mark-as-read firing after the pointer had left the entry
- Fixed folo:// links that launch the app being dropped, so following a feed or signing in from the browser did nothing
- Fixed the app not coming back after installing an update on Windows and Linux
- Fixed the app restarting signed out with default settings after a renderer update, and renderer updates never applying on Linux
- Fixed Check for Updates in the app and tray menus doing nothing when there was no update or the check failed
- Fixed the app running without a window when startup cleanup failed, for example when antivirus held an old file on Windows
- Fixed the HTTP cache limit deleting the newest files first and blocking the app while it ran
- Fixed setting changes made while settings were syncing never being sent, and AI settings being uploaded on every launch, which overwrote AI changes made on other devices
- Fixed your session being written to the Folo CLI config on every launch even if you never connected the CLI
- Fixed custom integration secrets and cookies being written to the log file
- Fixed Cmd+F filling the find bar with the clipboard; it now starts with the previous search
- Fixed AI replies that stopped arriving staying on "Thinking..." forever, stopped replies that couldn't be copied, and failed uploads being sent with the message
- Fixed the text-to-speech shortcut in an open article, playing an entry again after its speech ended, and pausing while the rest was still downloading
- Fixed the profile form refusing to save with a short display name, an empty handle or a handle saved by an older version
- Fixed an unverified email change being reported as done, and a failed account deletion signing you out
- Fixed undo after unfollowing a list, and undo losing the custom title of a feed
- Fixed sidebar lists and inboxes opening in the wrong view, and inboxes missing from the All view
- Fixed alphabetical sorting of subscriptions running in the opposite direction
- Fixed a subscribed feed opened by its link showing as a preview with a Follow banner
- Fixed a failed request replacing a cached entry with "Entry not found"
- Fixed the Zotero and qBittorrent integrations ignoring changed settings until a restart, and Obsidian notes for titles like "Q: ..." never showing up on Windows
- Fixed the image preview giving up instead of trying every image source
