Folo 是一款 AI RSS 阅读器：把你关注的一切汇集到一条清爽的时间线，再让 AI 帮你读。

博客、新闻网站、Newsletter、播客、视频频道和社交动态，都能在 Folo 里统一订阅。读到有疑问的内容直接问 AI，一键总结整条时间线，摘要和翻译也都交给它。

AI 陪你一起读
• 就一篇文章、一个订阅源、一个文件夹或整条时间线，和 AI 对话
• 一键总结时间线，快速了解今天的重点
• AI 任务：定时生成每日或每周简报，发送到对话或邮箱
• AI 摘要，以及中、英、日、法翻译，可双语对照，也可只看译文
• 自然流畅的文本转语音
• 接入 MCP 服务、自选 AI 模型，或使用自己的 API Key

一条时间线，装下你关注的一切
• 订阅任意 RSS、Atom 或 JSON Feed，也可以直接按名称搜索订阅源
• 借助数千条 RSSHub 路由，没有 RSS 的网站也能订阅
• 支持 OPML 导入导出，从其他阅读器迁移毫不费力
• 文章、社交动态、图片、视频、播客，各有专属布局
• 文件夹、收藏、列表，以及带专属邮箱地址、可接收 Newsletter 的收件箱

为桌面阅读而生
• 三栏布局，专注又高效
• 可自定义的快捷键与命令面板
• 自动化：按你的规则过滤、收藏、改写、通知或总结新内容
• 一键发送到 Obsidian、Readwise、Instapaper、Zotero、Cubox、Outline、Readeck 和 Eagle
• 主题、阅读字体、自定义 CSS 与代码高亮
• Spotlight 帮你高亮关心的关键词

随处接着读
订阅、已读状态和收藏在 Windows、macOS、Linux、Android、iPhone、iPad 和网页版之间同步。

开源，无广告
Folo 基于 AGPL-3.0 协议开源，没有广告，由读者和开发者社区一起公开打造。

会员方案
注册免费账户即可使用 Folo。Basic、Plus、Pro 会员提供更多订阅数量、更高的 AI 额度，以及 AI 任务、收件箱、自带 API Key 等能力。
